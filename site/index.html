AUDP Error Correction Mathematics Engine

Reliable payloads over unreliable links.

AUDP-ECM turns noisy or incomplete sensor and telemetry frames into exact payloads using classical algebraic coding: Reed–Solomon, BCH, CRC-16 and burst-resilient interleaving.

Python binding D binding

What it is

Field devices in agriculture send small messages over radio, long cables and shared channels. Interference flips symbols, bursts wipe out runs of bytes, and weak signals leave values unknown. AUDP-ECM is the software layer that detects and repairs this damage before the data is used.

Detect

CRC-16 and syndromes reveal that a frame was corrupted.

Correct

Reed–Solomon and BCH repair a bounded number of wrong symbols or bits.

Recover

Known-bad symbols are treated as erasures, which cost half as much redundancy as unknown errors.

Not cryptography. Error correction handles channel noise. It does not authenticate data or resist a deliberate attacker; use a MAC or AEAD for that.

Bindings

Python

CPython ≥ 3.10 · Linux, Windows, macOS · no runtime dependencies.

import audp_ecm as ecm

rs = ecm.ReedSolomon(31, 23)        # corrects 4 errors
cw = rs.encode(bytes(23))
rx = bytearray(cw); rx[3] ^= 0xFF
assert rs.decode(rx).data == bytes(23)

codec = ecm.BurstCodec.for_burst(31, 23, 64, 16)
tx = codec.protect(b"node=17;temp=21.7")
assert codec.recover(tx) == b"node=17;temp=21.7"

D

DMD or LDC · @safe API · RAII-managed resources.

import audp_ecm;

auto rs = ReedSolomon(31, 23);
auto cw = rs.encode(new ubyte[23]);
cw[0] ^= 0xFF;
assert(rs.decode(cw).correctedSymbols == 1);

auto msg = cast(immutable(ubyte)[]) "node=17;temp=21.7";
auto codec = BurstCodec(31, 23, 4);
assert(codec.recover(codec.protect(msg)) == msg);

Engineering quality

  • Memory-safe by construction: no unsafe code in the bindings; the D API is @safe.
  • Invalid input is rejected with typed errors — never a crash, never silent corruption.
  • Results are verified before they are returned; burst frames carry a CRC as a second check.
  • Known-answer, differential, property-based and adversarial tests run on Linux, Windows and macOS.
  • Dependencies are audited continuously; releases ship checksums and signed build provenance.
